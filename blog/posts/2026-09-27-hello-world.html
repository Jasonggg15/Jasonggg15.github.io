Hello, World

Sep 27, 2026 · 2 min read

I have been meaning to set up a proper corner of the internet for a while — a place that is mine, that loads fast, and that I fully control. This is it.

The plan is to write occasionally about research (what I am working on, what I got wrong along the way), about engineering, and about whatever else seems worth writing down. No schedule, no promises.

How this site is built

Deliberately boring technology: hand-written HTML and CSS, a few lines of vanilla JavaScript, and no build step. Every page is a file; every file is readable. If you are curious, the whole thing is inspectable with View Source. 

page/
├── index.html          # the main page
├── blog/               # this blog
└── assets/             # stylesheets, fonts, one script

Simplicity is a feature. The less machinery between an idea and the page, the more likely I am to actually publish it.

See you in the next one.
